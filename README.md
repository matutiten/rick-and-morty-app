# 🛸 Rick and Morty App - Trabajo Práctico Final

Aplicación web desarrollada en React con Vite para el **Curso Inicial Front-End de la UTN**.

## 📋 Descripción del Proyecto

Aplicación que consume la API pública de [Rick and Morty](https://rickandmortyapi.com/) para mostrar y gestionar personajes de forma dinámica. 

## 🚀 Características Principales

- **Integración con API:** Llamadas asíncronas usando `fetch` a la API de Rick and Morty.
- **Visualización en Cards:** Grilla de tarjetas con imagen, nombre, especie, estado y género (mínimo 4 datos por recurso).
- **Búsqueda en tiempo real (Plus):** Filtrado dinámico de personajes mientras el usuario escribe.
- **Página 404 personalizada (Plus):** Componente para rutas no encontradas usando React Router.
- **Manejo de estado:** Uso de `useState` y `useEffect` para gestionar datos, carga y errores.
- **Manejo de errores:** Validación de respuesta de la API.

## 🛠️ Tecnologías Utilizadas

- [React](https://react.dev/) (Librería de UI)
- [Vite](https://vitejs.dev/) (Build tool y servidor de desarrollo)
- [React Router DOM](https://reactrouter.com/) (Enrutamiento)
- CSS puro (Estilos)
